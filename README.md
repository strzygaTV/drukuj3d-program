# DRUKUJ 3D – drukarnia 3D, Bydgoszcz

**Strona dla klientów (cennik, wycena z pliku, kontakt):** https://strzygatv.github.io/drukuj3d-program/

**Aplikacja na Androida:** [pobierz APK](https://github.com/strzygaTV/drukuj3d-program/releases/download/beta/DRUKUJ3D-klient-beta.apk)

W tym repozytorium nie ma żadnych danych ani kluczy właściciela.

- `docs/` – strona dla klientów (druk z pliku, litery LED, neony i kasetony, lampy i abażury)
- `klient-android/` – aplikacja dla klientów (pokazuje tę samą stronę)
- `oferta.json` – filamenty dostępne od ręki, cennik usług, kontakt
- `katalog.json` – katalog „Na zamówienie” dla klientów
